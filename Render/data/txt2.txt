1.  [標題]：
    Node.js vm2 沙箱庫修復 NodeVM 巢狀執行沙箱逃逸漏洞

2.  [關鍵字]：
    node.js, vm2, sandbox, escape, vulnerability, execution, nested, exploit

3.  [發生時間]：
           正式發布：2026年5月11日 (CVE-2026-44007相關修補版本vm2 3.11.1發布)
       預計部署：受影響開發者應立即升級至vm2 3.11.2以確保防護完整性。

4.  [影響範圍]：
           作業系統版本：執行Node.js的環境 (例如：Windows, Linux, macOS)。
       適用對象：使用vm2函式庫（版本3.11.0及更早）在沙箱環境中執行外部或不可信JavaScript程式碼的Node.js應用程式與服務開發者。

5.  [潛在影響]：
        vm2核心價值在於提供受限環境執行JS，防止惡意代碼影響主機。此漏洞利用NodeVM `nesting:true`與`require:false`的矛盾設定，繞過沙箱邊界，使攻擊者能載入惡意模組並執行主機命令。其技術原理是破壞了基於虛擬機(VM)隔離的防禦能力，導致主機端遠端程式碼執行（RCE）。

6.  [重點整理]：
        Node.js 沙箱函式庫 vm2 近期修補了多項嚴重的沙箱逃逸漏洞，其中最新的是 CVE-2026-44007，影響 3.11.0 及更早版本，已於 3.11.1 版修復。此漏洞主要發生在開發者使用 NodeVM 時，若同時啟用 `nesting:true`（允許巢狀沙箱）卻誤以為已透過 `require:false` 禁用了模組載入功能，攻擊者便能利用此矛盾設定。惡意沙箱內程式碼可藉此重新載入 vm2 函式庫，並建立一個新的內層 NodeVM 沙箱，進而在主機端執行任意命令，實現沙箱逃逸與遠端程式碼執行（RCE）。

    vm2 旨在為 Node.js 應用提供一個受限制的環境來執行不可信任的 JavaScript 代碼，例如線上編譯器、插件系統等，以確保主機系統的安全。然而，一旦沙箱的隔離邊界被成功繞過，將對主機系統構成嚴重威脅。

    本次 3.11.1 版本的修補機制，是針對 `nesting:true` 且 `require:false` 這種自相矛盾的設定，直接拋出錯誤，以避免開發者誤判其安全性。鑑於 vm2 函式庫近期頻繁出現沙箱逃逸與 RCE 漏洞（包括先前的 CVE-2026-26956 及 3.11.0、3.11.2 版本的其他修補），強烈建議所有使用 vm2 的開發者務必將其升級至目前最新的 3.11.2 版本。同時，官方也提醒，vm2 不應被視為唯一的防線，建議搭配獨立程序、容器、虛擬機器或雲端託管執行環境等多層次安全防護，以最大限度降低潛在風險。
